qa-demo

Documentación del proyecto de automatización de pruebas con TypeScript · Repositorio: mariotalavera32/prueba_mario

1. Visión general

Proyecto de QA que combina varios niveles de prueba sobre sitios públicos de demostración: pruebas unitarias, E2E con Page Object Model, API, login, accesibilidad y regresión visual. Todo se ejecuta localmente y en GitHub Actions.

HerramientaUso
VitestPruebas unitarias y cobertura (unit/, src/)
PlaywrightE2E, API, login, accesibilidad y visual (tests/)
@axe-core/playwrightAuditoría de accesibilidad
GitHub ActionsIntegración continua (.github/workflows/qa.yml)

7. Flujo de una prueba visual

Las baselines se guardan sin depender del sistema operativo (snapshotPathTemplate) y con tolerancia maxDiffPixelRatio: 0.02, para que lo generado en Windows también pase en el CI de Linux.

8. Comandos

ComandoAcción
npm ci y npx playwright install chromium firefox webkitInstalación
npm testUnitarias + E2E
npm run test:unit / test:e2e / test:coverageCada nivel por separado
npx playwright test --project=firefoxUn solo navegador
npx playwright test tests/visual.spec.ts --project=chromium --update-snapshotsRegenerar baselines
npx playwright show-reportReporte HTML
